# speedpicture

スマホの写真・動画を Googleフォトへ送る前に、**メタ情報を全部消して、ついでに小さくする**準備ツールです。
ファイルを小さくした分だけ、アップロードにかかる時間と通信量が減ります。

「スマホ → Googleフォトを速くしたい」と「写真・動画のメタ情報（位置情報など）を完全に消したい」という2つの希望を1つに合わせたツールです。

## できること

- 写真（JPEG / PNG / WebP）のメタ情報を完全に削除
  - EXIF（位置情報・撮影日時・カメラ機種など）、PNGのテキストチャンクなどを、画素データから作り直す方式で除去します
  - 削除前に EXIF の向き情報を画素へ反映するので、縦写真が横向きに戻る事故が起きません
  - 変換結果の画面で、ファイルごとに「何件のメタ情報を消したか」と前後のサイズを表示します
- 動画（MP4 / MOV / M4V / WebM / MKV）のメタ情報を削除
  - ffmpeg のストリームコピー（再圧縮なし）で、タイトル・位置情報・チャプター等を除去します。画質は変わりません
  - ffmpeg が無い環境では動画はエラーとして報告します（消せていないファイルを「消えたこと」にして渡すことはしません）
- 2つのモード
  - **画質そのまま**: メタ情報だけ削除（JPEGは画質95で再保存、PNGは無劣化）
  - **高速**: 長辺2048pxまで縮小＋JPEG画質80で圧縮し、アップロードをさらに速くします（動画は再圧縮しません）
- 変換後は個別ダウンロード、または全件ZIPで一括ダウンロード

## Googleフォトへのアップロードについて（正直な注意）

このツール自体は Googleフォトへ直接アップロードしません。変換後のファイルをダウンロードして、Googleフォトのアプリ／Web からアップロードしてください。

理由: Googleフォトの公式API（Library API）は 2025年3月の仕様変更で、扱える範囲が「そのアプリが作成したコンテンツ」中心に制限され、利用には Google Cloud 側の OAuth プロジェクト登録も必要です。個人の小さいツールが「スマホの写真を直接・高速に送る」経路として使うには前提が重いため、このツールは「送る前のファイルを小さく・きれいに整える」ところを担当し、最後のアップロードは公式アプリ／Web に任せる設計にしています。

## 使い方

### Webアプリとして（スマホのブラウザから使えます）

```bash
pip install -r requirements.txt
python app.py        # http://localhost:5000
```

1. 写真・動画を選ぶ（複数可）
2. モードを選んで「メタ情報を消して変換」
3. 結果を確認して、個別またはZIPでダウンロード
4. ダウンロードしたファイルを Googleフォトへアップロード

変換したファイルはサーバー上の作業フォルダに **1時間だけ**置かれ、自動で削除されます。
位置情報を含む写真を公開サーバーで処理したくない場合は、上の手順で自分のPCで動かしてください（その場合、ファイルは自分のPCの外へ出ません）。

### Render へデプロイする場合

- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn app:app`
- 動画も処理したい場合は ffmpeg が入った環境が必要です（無い環境では画像のみ動作し、動画はエラー表示になります）

- Python / Flask / Pillow（画像）、ffmpeg（動画・任意）
